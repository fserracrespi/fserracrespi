## 🔬 Research experience

I previously conducted research on **Parkinson's disease progression**, developing machine learning and deep learning models using longitudinal clinical data to predict future disease severity.

This work was carried out in collaboration with the **University of Deusto**, the **University of Louisville – HIVE AI Innovation Studio**, and the **Universitat Ramon Llull**.

The project included predictive modelling, explainability analysis and the development of **SMART-PD**, an explainable tool for predicting Parkinson's disease severity.
